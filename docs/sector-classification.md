# 지수 대상 업종과 지분 공시 관리

사용자 업종분류(261025).xlsx의 26개 업종 시트를 코드로 조인했다. 원본 KOSPI200은 201종목, KOSDAQ150은 150종목으로 351개 고유 종목이며 모두 단일 업종에 매칭된다. 영문자 포함 6자리 신규 코드는 문자열로 보존한다. 원본 파일 자체는 공개 저장소에 업로드하지 않았다.

운영 파일:
- config/index-universe.json: 업로드 원본의 지수 대상 스냅샷
- config/sector-lookup.json: 제공된 업종 원본 전체의 코드-업종 대응표 (기업명 유사도 매칭 없음)
- dist/data/index-universe.json: 최근 공식 지수 조회에 성공한 목록과 분류 결과
- config/index-membership-history.json: 관측 기준일별 실제 편입·편출 기록

## 자동 변경

Update index universe and flow는 KST 평일 18:35 예약이며 FLOW_AUTO_UPDATE=true인 경우 예약 실행한다. KRX KOSPI200(1028), KOSDAQ150(2203) 지수의 실제 구성종목을 조회해 편입·편출을 반영한다. 지수명과 응답 개수·코드 형식을 검증하고 실패하면 기존 목록을 유지한다. 발표 예정일만으로 미래 구성종목을 미리 적용하지 않는다.

IPO는 상장만으로 이 유니버스에 포함하지 않는다. 실제 해당 지수에 편입된 시점부터 포함한다. 기존 업종 원본에 해당 코드가 있으면 자동 매칭하고, 원본에도 없는 신규 종목은 미분류로 표시한다. 분류를 이름이나 사업 키워드로 추정하지 않는다.

공급자 분류 갱신을 자동 연결하려면 Actions Variable FLOW_SECTOR_MAP_URL에 허용된 HTTPS JSON 공급원을 연결한다. 필요 시 Secret FLOW_SECTOR_MAP_TOKEN을 사용한다. 형식은 source, as_of, sectors(코드:업종명)이다. 웹페이지 자체가 이 형식의 API라는 의미는 아니다. 미분류 종목은 원본 갱신 또는 허용된 공급자 피드로 해소한다.

## 데이터 범위

확장 초기 데이터는 연기금·외국인 최근 26개 관측일과 공급자 5·10·20·60거래일 누적 집계다. 다른 주체의 과거 일별 이력은 미확보 시 null로 유지한다. 기간 집계액을 일별로 배분하지 않는다. 확장 가격은 비수정 종가이며 기존 커버리지 수정주가 데이터는 별도 보존한다. 확보 기간보다 긴 차트 선택에는 일부만 확보했다고 표시한다.

## 투자 주체

개인, 외국인, 기관계, 금융투자, 보험, 투신, 기타금융, 은행, 연기금등, 사모펀드, 국가, 기타법인, 내외국인(공급자 기타외국인)의 13개 구분이다. 기관계는 기관 7개 구성 주체 합계이며 이중 합산하지 않는다. 국가는 분리 제공이 없으면 미제공이다.

## 최근 연기금 지분 공시

국민연금 공시 비율만 연결한다. 전체 연기금 현재 지분율로 표현하지 않는다. 최신 대량보유 보고가 있으면 공시 접수일과 원문 링크를 표시하며 실제 보유 기준일을 모르는 경우 미확인으로 둔다. 보고자 본인 비율이 확인되지 않은 헤드라인은 보고자·특별관계자 합산 비율로 표시한다. 임원이나 다른 주요주주의 보유 비율을 국민연금 비율로 대체하지 않는다.

정기 OpenDART 갱신은 GitHub Secret DART_API_KEY가 있을 때 실행한다. 없으면 검증된 기존 공시 자료를 유지하고 갱신 미설정 상태를 기록한다. 연간 공시는 최신 지분변동 보고가 없을 때의 명시적인 과거 기준 자료다. 대량보유 API 주요 원천: https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS004&apiId=2019021
