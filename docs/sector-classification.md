# 전 종목 섹터 분류 설계

현재 운영 데이터는 기존 커버리지 10종목이며, 전 종목 수급 수집 및 WI26/WICS 매핑 원본은 아직 연결하지 않았다.

## 권장 구조

- 기본 탐색: WI26. WICS와 구분되는 26개 업종 분류다.
- 세부 비교: WICS 분류 코드·명칭을 별도 열로 보관한다.
- 리서치 태그: 조선·방산·건설기계 등 자체 관심군을 별도 다중 태그로 유지한다. 표준 업종을 태그로 덮어쓰지 않는다.
- 상장 종목 마스터에 공급자 영구 식별자 또는 ISIN, 6자리 단축코드, 시장, 주식 종류, 상장·폐지일을 저장한다.
- 분류 테이블은 security_id, system, sector_code, sector_name, valid_from, valid_to, source, fetched_at을 저장한다.
- 종목명 유사도로 자동 매칭하지 않는다. 원본 코드 기준으로 조인하고 미매칭·중복·분류 변경을 검증한다.
- 기본 유니버스는 KOSPI·KOSDAQ 보통주. 우선주·ETF·ETN·스팩·리츠는 별도 상품 유형으로 구분해 필터한다.
- 신규 상장과 미매칭은 미분류로 유지한다. 과거 분류 스냅샷을 보존해 백테스트에 현재 분류를 소급하지 않는다.
- 허용된 FnGuide/WiseIndex 원본 또는 CSV로 분류를 갱신한다. 공개 조회 가능 여부와 대량 수집·재배포 허용 여부를 구분한다.
- 분류 마스터는 전 종목으로 관리할 수 있지만, 모든 종목의 1년 세부 수급을 현재 종목별 요청 루프로 확장하지 않는다. 일별 전 종목 스냅샷·증분 저장·캐시 등 별도 수집 설계가 필요하다.

공식 분류 설명: https://www.wiseindex.com/About/WI26 및 https://www.wiseindex.com/About/WICS

## 현재 반영

- 프런트 업종 목록은 데이터에 존재하는 업종명에서 생성한다.
- 데이터 검증은 특정 3개 업종만 허용하던 제한을 제거했다.
- 표준 분류 데이터 미확보 상태에서 기존 종목을 임의로 WI26/WICS에 매칭하지 않았다.

## 보유 지분율

외국인 지분율과 시가총액은 기존 일별 KRX 수집값을 사용한다. 국민연금 공시 지분율은 전체 연기금의 현재 보유 비율이 아니다. 별도 JSON에서 보유 기준일, 공시일, 출처와 함께 제공하며, 조회 데이터 기준일 이전에 공개된 자료만 표시한다.

현재 국민연금 자료: 2025-12-31 보유, 2026-08-11 공시.
https://fund.nps.or.kr/impa/edwmpblnt/getOHEF0006M0.do?tmpltdataSn=5931&cat=YEA

원본 XLSX를 내려받아 다음 명령으로 현재 커버리지와 정확한 이름/확인된 구명칭을 매칭한다:

    python scripts/import-nps-holdings.py <source.xlsx> --as-of 2025-12-31 --published-at 2026-08-11 --source-url '<공식 공시 URL>'

출력: dist/data/pension-holdings.json. 신규 공시를 확인한 뒤 동일 방식으로 갱신한다. 지분율에 이후 순매수 금액을 더해 현재 보유 비율을 만들지 않는다.
